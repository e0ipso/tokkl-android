Where the wordmark images in res/drawable-nodpi/tokkl_wordmark_*px.png come from

Source: the owner's clock O wordmark in Tokkl's wordmark pack (github.com/e0ipso/tokkl
at df6711b), the raster master, PNG only:
  ../tokkl/docs/brand/wordmark-pack/source/tokkl-wordmark-clock-master.png,
  2067x761 RGBA, SHA-256
  0d4164b01e9452f10387694cc192e192e57fe0d486e51cb66f3e186e44f858ca
The clock in place of the "o" is a letter of the wordmark, not the logo. The logo is
the launcher icon and the decorative artwork before page titles.

Crop: the rule of Tokkl's WORDMARK_CROP in ../tokkl/scripts/icons.ts, the letters
and paint spots inside the source's transparent margin, plus 4 px. Here that is
the alpha bounds, 2051x761+16+0, plus a 4 px transparent border: 2059x769.

Sizes: ui/Brand.kt draws the wordmark 260 dp wide (lg, as in Tokkl's Brand.tsx),
on sign-in, and the launch splash draws the same images. Tokkl's sm and md, 84
and 130 dp, do not ship: no screen shows them. lg has its own image in each
density bucket, at 1x (mdpi), 1.5x (hdpi), 2x (xhdpi), 3x (xxhdpi) and 4x
(xxxhdpi), so it draws from an image made for its width near the screen's
density, never from a larger one scaled down. Widths in px:
  lg 260 390 520 780 1040
The widest, 1040 px, is under the crop's 2059 px, so nothing is upscaled.

Files: each width ships once, as res/drawable-nodpi/tokkl_wordmark_Wpx.png: 5
wordmarks. res/values/brand_images.xml (mdpi) and values-hdpi to
values-xxxhdpi/brand_images.xml alias tokkl_wordmark_lg to the width the table
gives for that bucket, and ui/Brand.kt and both splash_wordmark.xml files ask
only for that name. The images sit in drawable-nodpi, not in the density
folders, so lint's IconDuplicates check finds no file twice, and its
IconDensities check, which wants each density folder to hold the same images,
finds no drawable density folder to compare. Android does not rescale a nodpi image when it loads it; Brand.kt draws
it at its dp size.

Built with ImageMagick 7.1.1-43 with Tokkl's own steps from scripts/icons.ts:
crop, resize, then reduce to a 256-colour palette with alpha, and strip metadata
and timestamps. W is the width in px for one bucket:
  magick tokkl-wordmark-clock-master.png -trim +repage -bordercolor none
    -border 4 -resize Wx -colors 256 -strip -define png:exclude-chunks=date,time
    png:drawable-nodpi/tokkl_wordmark_Wpx.png
Tokkl's npm run icons still cuts packages/web/public/brand/wordmark-260.png and
wordmark-520.png from the earlier tokkl-wordmark-v3.png, so these files do not
match them.

This note lives in res/raw because the build accepts only drawable files in
res/drawable-*.

The page-header logo, res/drawable-nodpi/tokkl_logo.png, is a byte-for-byte copy
of ../tokkl/docs/brand/icon-pack/logo/color-256.png. TokklTopBar draws it at
48dp, followed by an 8dp gap and the page title.
