# Tokkl for Android

Native Android client for the Tokkl server and for Toggl Track, for Android 12 (API 31) and later. The repo holds a Gradle project. After sign-in, a bottom navigation bar, or a navigation rail on wider windows, holds Timer, Pomodoro, Projects, Settings and More, in that order. More opens Reports, Timer templates, Clients, Tags and Trash where supported. Each page shows its title in a top bar. The Timer page starts, stops and edits the running entry. It lists past entries by day, grouping similar ones as the web app does, or shows them on a week calendar, and it duplicates a listed entry or deletes it with Undo. An entry screen edits every field of a past entry or adds one by hand. The Pomodoro page sets work and rest lengths, the long-rest interval and entry fields. Work alternates with short or long rests; Next phase advances it, with overtime until confirmed. At each planned end an alarm loops until Next phase or End session, with a full-screen alarm over the lock screen when permitted. The page shows denied notification, exact-alarm and full-screen access with controls to request it. Reports has the summary, detailed and weekly reports, with the web app's filters. The Projects and Clients pages create, edit, archive and restore projects and clients on the server, and a project's form manages its tasks. The Tags page creates, renames and deletes tags. On a Tokkl server, the Trash page lists deleted entries, restores them and deletes one or all for good. Settings signs out, which clears the account's data from the phone, and opens a Licences screen. On a Tokkl server with the timer API, Pomodoro sessions and pauses belong to the server: the phone shows the server's state, so other devices see and end them too, and starting, advancing or ending a session and Pause, Resume and Stop while paused need a connection. Pomodoro and Pause are hidden on Toggl Track and on older Tokkl. A foreground sync service holds the server's event stream and shows a silent ongoing notification, "Timer sync is on". While a timer runs, an ongoing notification shows it with a ticking clock and a Stop button that works offline. A session notification shows the Pomodoro phase and countdown, with Next phase and End session buttons, when notifications are allowed. Both buttons go to the server. Separate Timer and Pomodoro home screen widgets show the running timer and day report, or the server session and countdown. Timer Start, ordinary Stop and templates use the offline queue; Pause, Resume, Stop while paused and session actions need a connection. Under the screens sit an offline cache of the account's data and a queue that sends time entry changes made on the phone in order, also in the background when the network returns. [docs/PRD.md](docs/PRD.md) is the source of truth for scope and decisions.

- The server lives in the sibling repo `../tokkl` (github.com/e0ipso/tokkl). Its `docs/PRD.md` section 6 lists the Toggl API v9 and Reports v3 endpoints Tokkl implements, and section 4 has the visual direction this app borrows from.
